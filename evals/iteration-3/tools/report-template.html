What this comparison tests

The revision asks for different rendered compositions before committing, qualifies restrictive visual rules, and adds an optional shape reference. Adjusted Squircle is the user’s preferred continuous-corner treatment when suitable. It is not a default style for every product.

All final screenshots use the same task data, state, viewport, theme, clock, and capture settings. They have not been repaired after generation. Equal scale preserves differences in density and clipping.

Limits and provenance

This is a small, bundled intervention. It cannot establish statistical significance or identify which individual instruction caused a result. Local preference choices are personal review data, not an independent user study. Screenshot metrics support inspection; they do not grade overall design quality.

All design attempts for this cohort are retained. An earlier pilot was excluded as a whole because its shared contract induced unequal workloads. The primary cohort uses only task-specific requirements and the same frozen skill versions.
