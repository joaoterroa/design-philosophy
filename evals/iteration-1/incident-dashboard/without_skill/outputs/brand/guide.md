# Northwind Logistics — Brand guidelines (v3, 2025)

## Logo
The Northwind wordmark is set in IBM Plex Sans SemiBold with the "compass N" symbol to its left. Minimum height 16px on screen. Never recolour the symbol except to white on Harbor Navy.

## Colour
| Name | Hex | Use |
| --- | --- | --- |
| Harbor Navy | #12355B | Primary. Logo, headers, primary buttons. |
| Signal Orange | #F26B21 | Accent. Calls to action, highlights. Use sparingly. |
| Tide Teal | #2A9D8F | Secondary accent for illustrations and charts. |
| Fog | #EEF1F4 | Light backgrounds. |
| Slate | #3D4852 | Body text. |
| White | #FFFFFF | |

Do not use Signal Orange for large areas or body text.

## Typography
IBM Plex Sans (Regular, Medium, SemiBold) for all digital products. IBM Plex Mono for code, IDs and tabular figures. Fallback: system sans-serif.

## Voice
Direct, calm, competent. We move freight; we don't do hype.
